## How to contribute

1. Fork this repository and clone locally
2. Create a branch: `git checkout -b fix/your-change`
3. Make your changes with clear, descriptive commit messages
4. Open a Pull Request with a short explanation of what changed and why

### Commit message convention

Please follow [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: add new section to profile README
fix: correct broken badge URL
docs: update strategy guide with new projects
chore: update CI workflow to Node 20
```

---

## Reporting issues

If you spot a broken link, an outdated badge, or any other issue with the profile, please open a GitHub Issue using the bug report template.
